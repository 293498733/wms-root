### 1.3 数据流向

```
【模块 C：物流单提交流程 - 数据流向】

提交请求 → Controller → Service.submit()
  │
  ├─ Step 1: 校验 repair_notice 存在且状态为 "3"(处理中)
  │    读取: repair_notice (by id)
  │
  ├─ Step 2: 校验明细 SKU 属于通知单
  │    读取: repair_notice_detail (by notice_id)
  │
  ├─ Step 3: 校验各 SKU 数量 ≤ 可发运余量
  │    读取: repair_notice_detail (所有SKU清单)
  │    读取: repair_logistics_order_detail (关联repair_notice_id的所有已提交/已发运物流单的明细，按sku_id汇总quantity)
  │    计算: 可发运余量 = 1 - 已发运数量总和  (因 repair_notice_detail 无 quantity 字段，每个 SKU 的基准量为 1)
  │
  ├─ Step 4: 更新物流单状态为 "1"(已提交)
  │    写入: repair_logistics_order.status = "1"
  │
  └─ Step 5: 汇总判定
       读取: repair_logistics_order_detail (按 repair_notice_id 统计所有已提交+已发运物流单的 quantity)
       判定: 若每个 SKU 的累计物流数量 ≥ 1 → 更新 repair_notice.status = "5"
       写入: repair_notice.status = "5"(已完成)
```

### 2.3 汇总判定逻辑（接口 6 的附加逻辑）

提交物流单后，执行以下步骤：

```
boolean allComplete = true;
for each skuId in 通知单的所有SKU:
    totalShipped = SUM(repair_logistics_order_detail.quantity)
                   JOIN repair_logistics_order
                   WHERE repair_logistics_order.repair_notice_id = ?
                     AND repair_logistics_order.status IN ('1','2')
                     AND repair_logistics_order.del_flag = '0'
                     AND detail.sku_id = ?
    if (totalShipped < 1):
        allComplete = false;
        break;

if (allComplete):
    UPDATE repair_notice SET status = '5' WHERE id = ?;
```

```java
@Transactional(rollbackFor = Exception.class)
public void submit(RepairLogisticsOrderBo bo) {
    // 1. 校验物流单存在且状态=草稿
    RepairLogisticsOrder order = getByIdRequired(bo.getId());
    if (!"0".equals(order.getStatus())) {
        throw new ServiceException("仅草稿状态的物流单才能提交");
    }
    
    // 2. 校验关联返修通知单存在且状态=处理中(3)
    RepairNotice notice = repairNoticeMapper.selectById(order.getRepairNoticeId());
    if (notice == null) {
        throw new ServiceException("关联的返修通知单不存在");
    }
    if (!"3".equals(notice.getStatus())) {
        throw new ServiceException("返修通知单状态需为处理中");
    }
    
    // 3. 校验明细 SKU 必须属于通知单
    Set<Long> noticeSkuIds = repairNoticeDetailService.querySkuIdSetByNoticeId(order.getRepairNoticeId());
    // 从数据库读取最新明细
    List<RepairLogisticsOrderDetail> details = getDetailsByOrderId(bo.getId());
    for (RepairLogisticsOrderDetail detail : details) {
        if (!noticeSkuIds.contains(detail.getSkuId())) {
            throw new ServiceException("SKU(ID=" + detail.getSkuId() + ")不在该返修通知单的关联SKU列表中");
        }
    }
    
    // 4. 校验每个 SKU 数量 ≤ 可发运余量
    //    可发运余量 = 1（通知单基准）- 已发运数量（所有已提交/已发运物流单中该 SKU 的合计）
    Map<Long, BigDecimal> shippedMap = getShippedQuantityByNoticeId(order.getRepairNoticeId());
    for (RepairLogisticsOrderDetail detail : details) {
        BigDecimal alreadyShipped = shippedMap.getOrDefault(detail.getSkuId(), BigDecimal.ZERO);
        // 包含当前物流单的修改（若 submit 中已更新明细）
        BigDecimal shippable = BigDecimal.ONE.subtract(alreadyShipped);
        if (detail.getQuantity().compareTo(shippable) > 0) {
            throw new ServiceException("SKU({})发运数量({})超过可发运余量({})");
        }
    }
    
    // 5. 更新状态
    LambdaUpdateWrapper<RepairLogisticsOrder> wrapper = Wrappers.lambdaUpdate();
    wrapper.eq(RepairLogisticsOrder::getId, bo.getId());
    wrapper.set(RepairLogisticsOrder::getStatus, "1");
    repairLogisticsOrderMapper.update(null, wrapper);
    
    // 6. 汇总判定
    autoCompleteRepairNoticeIfAllShipped(order.getRepairNoticeId());
}
```

**汇总判定逻辑 — autoCompleteRepairNoticeIfAllShipped()：**
```java
private void autoCompleteRepairNoticeIfAllShipped(Long repairNoticeId) {
    // 获取通知单所有 SKU
    Set<Long> noticeSkuIds = repairNoticeDetailService.querySkuIdSetByNoticeId(repairNoticeId);
    if (noticeSkuIds.isEmpty()) return;
    
    // 获取每个 SKU 的已发运总量
    Map<Long, BigDecimal> shippedMap = getShippedQuantityByNoticeId(repairNoticeId);
    
    // 判定：每个 SKU 的已发运数量 ≥ 1（基准）
    for (Long skuId : noticeSkuIds) {
        BigDecimal shipped = shippedMap.getOrDefault(skuId, BigDecimal.ZERO);
        if (shipped.compareTo(BigDecimal.ONE) < 0) {
            return; // 还有未发完的 SKU
        }
    }
    
    // 全部发完，更新通知单状态
    LambdaUpdateWrapper<RepairNotice> wrapper = Wrappers.lambdaUpdate();
    wrapper.eq(RepairNotice::getId, repairNoticeId);
    wrapper.set(RepairNotice::getStatus, "5");
    repairNoticeMapper.update(null, wrapper);
}
```
